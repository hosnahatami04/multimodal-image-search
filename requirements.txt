# ---------------------------------------------------------------------------
# Exact pins, not ranges.
#
# These are the versions the committed numbers in results/ were produced with.
# A range like `transformers>=5` would let a future `pip install` change the
# README's metrics without a single line of this repository changing, and the
# drift would be indistinguishable from a real change in model quality.
#
# NOTE: torch / torchvision are deliberately NOT listed here.
#
# On Windows, a plain `pip install torch` pulls the CUDA build (~2.5 GB) even
# on a machine with no NVIDIA GPU. This project is CPU-only, so torch has to be
# installed from the PyTorch CPU index first:
#
#   pip install torch==2.14.0 torchvision==0.29.0 \
#       --index-url https://download.pytorch.org/whl/cpu
#
# `make install` runs both steps in the right order.
# ---------------------------------------------------------------------------
